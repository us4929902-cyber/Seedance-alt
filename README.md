# Simple To-Do (LocalStorage)

A minimal single-page To-Do application that saves tasks in browser localStorage.

Features:
- Add tasks
- Edit tasks (inline)
- Delete tasks
- Toggle completed
- Filter: All / Active / Completed
- Clear completed
- Persisted in localStorage (no backend)

How to run:
1. Download these files (index.html, styles.css, script.js)
2. Open `index.html` in your browser (double-click or drag into browser)
3. Start adding tasks — they will persist in your browser

Optional:
- To share between devices, export/import localStorage or connect to a backend (not included).
